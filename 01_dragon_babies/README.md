# 龍年寶寶是真的嗎？

**2012 年龍年，全國多生了 3.6 萬個寶寶；2024 年龍年，只多了 874 個。**

![主圖](fig/01-main.png)

龍年寶寶是真的嗎？

在台灣，很多人都聽過「龍年寶寶特別多」：有人擔心孩子將來升學競爭激烈，社群上也有媽媽分享，為了避開龍年刻意晚一點生。這個說法在 12 年前確實成立。2012 年全國出生 23.5 萬人，比前一年多了 18.3%；龍年一過，2013 年又掉了 16.9%。

但到了 2024 年，畫面完全不同。這一年出生 13.5 萬人，只比 2023 年多 0.7%。從圖上看，2012 年的龍年像一座小山，2024 年卻只是一段平台：自 2016 年起連年下滑的出生數，在龍年暫時停住，但沒有再往上衝。

平台之後是更陡的下坡。2025 年出生數只剩 10.6 萬人，一年少了 21.6%，是 2007 年以來最大的跌幅。這可能有一部分是寶寶提前在龍年出生，但 2026 年的出生數仍持續創新低，顯示主因還是少子化本身。在台灣，生肖或許還能讓出生數撐住一年，卻已經推不高了。

資料來源與限制： 年度數字來自內政部戶政司「縣市出生按生母五齡組」（按發生日期），月資料來自「縣市出生死亡結婚離婚」（按登記日期，比實際出生約晚 1–2 個月）。本文比較的是出生數，沒有扣除育齡女性人數減少的影響；龍年效應與疫情、經濟等其他因素，也無法完全分開。



## 資料來源與限制
- 年度：內政部戶政司「縣市出生按生母五齡組」（按發生日期），2007–2025
- 月度：內政部戶政司「縣市出生死亡結婚離婚」（按登記日期），2011/01–2026/10
- 月資料比實際出生約晚 1–2 個月；本文比較的是出生數，沒有扣除育齡女性人數變化的影響
